# Johnson & Wilner LLP Website

Official website for **Johnson & Wilner LLP** — Business and Technology Law Firm in Abuja, Nigeria.

This is a full rewrite from Django to **Node.js + Express + EJS**.

---

## 🚀 Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/AndreUdotai/johnson-and-wilner.git
cd johnson-and-wilner

2. Install Dependencies
npm install

3. Start the Development Server
npm run dev
The website will be running at http://localhost:3000


Tech Stack

Backend: Node.js + Express
Frontend: EJS (Embedded JavaScript Templates)
Styling: Bootstrap 5 + Custom Theme (AttorCO)
Static Assets: CSS, JS, Images
