
# Contributing to Johnson & Wilner LLP Website

Thank you for contributing to the Johnson & Wilner LLP website project!

## Development Workflow

1. **Always work on a new branch**
   - Never push directly to `main`

2. **Create a feature branch**
   ```bash
   git checkout main
   git pull origin main
   git checkout -b feature/your-task-description

3. Make your changes

- Run the project locally: npm run dev
- Test your changes thoroughly

4. Commit your changes

- git add .
- git commit -m "feat: short description of what you did"

5. Push your branch

- git push origin feature/your-task-description

6. Create a Pull Request (PR)

- Go to GitHub and create a Pull Request from your branch to main
- Fill in the PR description clearly

7. Local Setup

- npm install
- npm run dev


The site will be available at http://localhost:3000
